# 유진이네 사이버 집들이

`index.html`을 정적 웹 호스팅에 올려 사용할 수 있는 모바일 우선 배치 도구입니다.

## 사용

- 모바일에서는 도면을 화면에 고정하고, 아래 가구 서랍 안에서만 목록을 스크롤합니다. 선택 가구의 회전·삭제와 이미지 저장은 아래쪽에 계속 표시됩니다.
- 냉장고, 세탁기, 옷장, 침대, 컴퓨터 책상, 선택 가구인 화장대 중 필요한 가구를 직접 골라 도면에 놓습니다.
- 2인 소파, TV장, 거실 테이블, 식탁·의자, 책장, 서랍장, 협탁, 칸막이, 신발장 등 추가 가구 10종도 선택할 수 있습니다.
- 도면에서 놓을 위치를 탭한 뒤, 가구를 드래그해 옮기거나 회전·삭제할 수 있습니다.
- 벽에 가까이 놓으면 약 250mm 이내에서 벽에 맞춰 정렬됩니다. 칸막이는 회전해 공간을 나눠 볼 수 있습니다.
- 가구 크기를 수정하고 직접 만든 가구를 이름과 크기로 추가할 수 있습니다.
- 배치안은 현재 기기의 브라우저에 저장되고, PNG 이미지로 내려받을 수 있습니다.
- 배치 초기화는 도면의 가구를 비우고 가구 크기를 기본값으로 되돌리며 저장한 배치안은 유지합니다.

## GitHub Pages로 올릴 때

저장소 루트에 `index.html`을 올리고 GitHub Pages의 배포 소스를 설정하면 됩니다. GitHub Pages는 저장소가 비공개여도 사이트가 인터넷에 공개될 수 있으니, 집 도면을 공개해도 괜찮은지 확인한 뒤 배포하세요. [GitHub Pages 공개 범위 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

배치 상태는 기기 안에만 저장되며, 친구와 편집 내용을 동기화하지 않습니다. 공유는 PNG 이미지로 하도록 구성했습니다.

## 도면에 관한 참고

평면도에 표시된 4,520mm 전체 너비와 침실 깊이 약 3,050mm를 기준으로 단순화해 다시 그린 참고도입니다. 침대·소파 등 기본 가구 치수는 일반 제품 예시를 참고한 값이며, 실제 제품 치수를 알면 목록의 mm 값을 수정해 사용하세요. 실제 벽체와 출입구, 설치 가능 여부는 현장 상태에 따라 다를 수 있습니다.
